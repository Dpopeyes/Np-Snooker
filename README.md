## 🚀 ฟังก์ชันหลักของระบบ

1. **⚡ โหมดคำนวณด่วน (Quick Calculator):**
   - **ใส่เวลาแบบ ชั่วโมง.นาที ได้โดยตรง เช่น `1.50` = 1 ชั่วโมง 50 นาที** (หรือ `1.20` = 1 ชม. 20 นาที, `0.45` = 45 นาที, `2.00` = 2 ชม.) ระบบจะคำนวณราคาให้ทันที!
   - มีปุ่มลัดเวลาด่วน (`0.30`, `0.45`, `1.00`, `1.30`, `1.50`, `2.00`)
   - หรือเลือกคำนวณจากเวลาเริ่ม - จบ (รองรับการข้ามเที่ยงคืน) หรือระบุ ชม./นาที
   - แจกแจงรายละเอียด: ชั่วโมงเต็มกี่บาท, เศษนาทีตรงแถวไหนในตาราง และสรุปยอดสุทธิ
   - เพิ่มค่าน้ำ / อาหาร / เบียร์ ได้ทันที

2. **⏱️ โหมดโต๊ะสด & จับเวลา Real-time (Live Tables & Timers):**
   - ควบคุมโต๊ะได้พร้อมกันทุกโต๊ะ (โต๊ะ 1, โต๊ะ 2, โต๊ะ 3, โต๊ะ 4, V1, V2)
   - เปิดโต๊ะ, พักเวลาชั่วคราว, แก้ไขเวลาเปิดโต๊ะย้อนหลังได้
   - เพิ่มรายการเครื่องดื่ม / อาหาร เข้าบิลของแต่ละโต๊ะได้
   - นาฬิกานับเวลาและยอดเงินอัปเดตสดทุกวินาที
   - สามารถกดเพิ่มโต๊ะใหม่เองได้ตามต้องการ

3. **📱 สแกนจ่าย PromptPay QR Code:**
   - สร้าง QR Code พร้อมเพย์ตามยอดเงินของบิลโดยอัตโนมัติ
   - ลูกค้าสามารถใช้แอปธนาคารสแกนจ่ายได้ทันที
   - ตั้งค่าเบอร์โทรหรือเลขพร้อมเพย์ของร้านได้

4. **🖨️ พิมพ์ใบเสร็จ & 💬 คัดลอกส่ง LINE:**
   - กดปุ่มพิมพ์สลิปใบเสร็จขนาดมาตรฐาน
   - กดปุ่ม "คัดลอกส่ง LINE" เพื่อนำข้อความสรุปไปส่งให้ลูกค้าได้ใน 1 คลิก

5. **📊 ตารางราคาเปรียบเทียบ:**
   - หน้าแสดงตารางราคาคู่ 2 ฝั่งเหมือนในรูปจริง พร้อมช่องค้นหานาทีเพื่อไฮไลท์แถวที่ตรงกัน

6. **📑 ระบบบันทึกประวัติการเช็คบิล & ยอดขายประจำวัน:**
   - เมื่อปิดโต๊ะ ข้อมูลจะถูกบันทึกเก็บไว้ใน LocalStorage ทันที ปิดเบราว์เซอร์แล้วเปิดใหม่ข้อมูลไม่หาย

ระบบมีระบบล็อกอินเพื่อความปลอดภัยในการจัดการโต๊ะและบิล สามารถเข้าใช้งานได้ 2 บัญชี:
- **👤 แคชเชียร์ (Cashier):**
  - **PIN:** `1234`
  - หรือ Username: `staff` / Password: `1234`
- **👑 เจ้าของร้าน (Admin):**
  - **PIN:** `9999`
  - หรือ Username: `admin` / Password: `admin1234`
- *มีแป้นพิมพ์ตัวเลข (Numpad) บนหน้าจอ เหมาะสำหรับจอสัมผัส POS หรือมือถือ*
- *มีปุ่มลัดคลิกเดียวเข้าสู่ระบบได้ทันทีสำหรับทดสอบ*
- *สามารถเปลี่ยนรหัส PIN ได้ที่ไอคอนฟันเฟือง `⚙️` บนแถบเมนู*
